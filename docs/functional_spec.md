# ZenX AI聊天应用功能规范

## 一、应用功能概述

ZenX是一款支持多AI服务商和角色扮演的聊天应用，采用双抽屉设计使用户能够灵活切换AI角色和调整模型设置。主要功能包括：

1. **AI助手角色切换**：通过左抽屉，用户可在不同AI角色间切换
2. **模型参数设置**：通过右抽屉，针对每个助手进行个性化配置
3. **多API服务商支持**：OpenAI，Anthropic Claude，Google Gemini等
4. **会话管理**：创建、保存和管理对话历史
5. **媒体支持**：上传图片并与AI讨论
6. **数据导出**：导出对话内容和设置

## 二、屏幕流程与交互

### 1. 启动流程
1. 启动应用 → 主聊天界面
2. 首次启动自动打开左抽屉，提示选择助手
3. 若未配置API，提示进入设置配置API密钥

### 2. 主聊天界面交互
- **标题栏**：
  - 中间显示当前对话标题，标题下面小字显示当前使用的助手
  - 左侧菜单按钮打开左抽屉
  - 右侧加号按钮创建新对话
- **内容区**：
  - 显示消息对话历史
  - 空白对话状态显示"开始新的对话"提示
  - 消息流式显示时展示打字动画
- **输入区**：
  - 可扩展多行输入框
  - 右侧"+"按钮打开功能面板（图片上传等）
  - 输入框有文字时右侧出现发送按钮
  - 显示发送按钮时输入框流畅地减小宽度
- **手势**：
  - 右滑：打开左抽屉（选择助手/历史）
  - 左滑：打开右抽屉（模型设置）

### 3. 左侧抽屉交互
- **标签页**：
  - "助手"标签：显示可选择的AI角色列表
  - "历史记录"标签：显示所有历史对话
- **助手标签内容**：
  - 助手列表项：图标、名称、简短描述
  - 点击选择后自动关闭抽屉
  - 当前选中的助手高亮显示
- **历史标签内容**：
  - 按照助手分类显示历史记录
  - 按时间倒序排列
  - 点击历史记录项加载对应对话
- **底部操作**：
  - 设置按钮：进入设置界面

### 4. 右侧抽屉交互
- **标题**：
  - 显示当前助手名称和"设置"
- **参数设置**：
  - 系统提示词（可编辑文本区域）
  - 模型选择（下拉菜单，根据已配置API可选）
  - 上下文长度（数值选择）
  - 流式输出（开关选择）
  - 温度调节（滑块，可选）
- **底部操作**：
  - "应用设置"按钮：保存当前设置并关闭抽屉

### 5. 设置界面交互
- **API配置**：
  - 显示已配置的API服务商列表
  - 每个API服务商显示状态（已配置/未设置）
  - 点击进入详细配置页（输入API密钥等）
  - "添加新API"按钮：添加新的API服务商
- **导出功能**：
  - "导出对话"：导出选定对话或全部对话
  - "导出设置"：导出应用设置（不包含密钥）
- **应用主题**：
  - 跟随系统/浅色/深色三选一

## 三、核心功能详细规范

### 1. 助手系统

#### 预设助手
应用内置以下基础助手角色：

| 助手名称 | 描述 | 默认API服务商 |
|---------|------|-------------|
| 通用助手 | 全能型AI助手，回答各类问题 | OpenAI |
| 编程专家 | 擅长编程、代码和技术问题 | OpenAI |
| 写作助手 | 帮助改进写作，创作文章 | Claude |
| 学习导师 | 解释概念，辅助学习 | Gemini |

#### 助手设置项
每个助手可独立配置：
```
- 系统提示词（定义助手角色和行为）
- API服务商选择
- 模型选择
- 上下文长度
- 流式输出开关
- 温度设置（0.0-1.0）
```

#### 助手创建流程
1. 左侧抽屉底部"创建助手"
2. 输入名称、描述
3. 选择图标（或默认图标）
4. 设置系统提示词
5. 配置模型参数
6. 保存并自动选择新助手

### 2. 对话会话管理

#### 会话状态
```
- 活跃会话：当前正在进行的对话
- 已保存会话：历史对话，按助手分类
```

#### 会话操作
- **新建会话**：点击右上角"+"按钮
- **保存会话**：自动保存，可手动命名
- **删除会话**：历史记录中长按或滑动删除
- **重命名会话**：长按会话标题进行编辑

#### 会话存储
- 本地存储所有对话历史
- 提供云备份选项（未来扩展）

### 3. API集成系统

#### 支持的API服务商
- OpenAI (GPT模型)
- Anthropic (Claude模型)
- Google (Gemini模型)
- 自定义API服务（支持OpenAI兼容接口）

#### API配置项
```
- API密钥
- 基础URL（允许自定义端点）
- 模型列表（自动获取或手动设置）
- 使用代理开关（可选）
- 并发请求限制（可选）
```

#### API密钥安全
- 使用系统加密存储API密钥
- 不在云端存储密钥
- 可选择使用生物识别锁定敏感设置

### 4. 媒体支持

#### 图片上传
- 输入框旁"+"按钮 → 图片上传
- 支持从相册选取或拍照
- 支持多图片上传（取决于API能力）
- 图片压缩和格式转换

#### 支持图片的助手
不是所有API都支持图片，应用智能处理：
- 显示当前助手是否支持图片
- 不支持时提示切换到支持图片的模型

### 5. 导出与备份

#### 导出格式
- **对话导出**：
  - 纯文本格式（.txt）
  - Markdown格式（.md）
  - HTML格式（可选）
- **设置导出**：
  - JSON格式（不含API密钥）

#### 导出操作
- 设置 → 导出备份 → 选择导出项
- 可选择导出范围：单个对话/所有对话
- 分享到本地应用或云存储

## 四、特殊功能流程

### 1. 首次启动向导
1. 欢迎界面：应用介绍
2. API配置：引导设置第一个API
3. 助手选择：选择默认助手
4. 主界面提示：引导用户熟悉UI

### 2. 对话上下文处理
- 管理会话长度，避免超出上下文窗口
- 提供上下文压缩选项（总结历史消息）
- 当接近上下文限制时提示用户

### 3. 设备离线处理
- 检测网络状态，离线时提供适当提示
- 保存未发送成功的消息，恢复网络后重试
- 提供离线浏览历史对话功能

## 五、非功能性需求

### 性能目标
- 应用启动时间 < 2秒
- 消息响应时间 < 500ms（不含API响应时间）
- 流式响应首字符显示 < 1秒
- 内存占用 < 100MB（正常使用）

### 安全目标
- API密钥存储采用设备级加密
- 不收集无关用户数据
- 本地数据库加密存储敏感信息

### 可访问性目标
- 支持屏幕阅读器
- 支持高对比度模式
- 支持文本大小调整
- 支持深色模式
